# Coordinated fixes for the September 5 review

Scope: findings 1–2 in [findings.md](findings.md) and issues 1–2 in the [Copilot issue review](https://techrawcull.netlify.app/docs/copilot/issues/).

## Implementation order and boundaries

1. JPEG export: enforce exclusive creation in `SaveJPGImage`, shared by embedded and demosaiced export. On a filesystem collision, retry `name (1).jpg`, `name (2).jpg`, etc. No existence-check race or overwrite authorization is introduced. Other write failures propagate through the existing export failure reporting.
2. Model release state: disable SAM 3 selection, local resource loading, and downloads; retain its blocked provenance and mark its prepared descriptor blocked. Add a fail-closed provenance verifier to release preflight and a standalone `make verify-model-provenance` target. Derive enabled models from inclusion declarations; validate readiness, archive identity/size/hash, and notice hashes. Transcribe the existing documented CLIP archive evidence into the provenance records. This does not approve SAM 3 distribution.
3. Quit recovery: keep one deferred termination request through repeated save attempts. Suppress the ordinary persistence alert while quit owns recovery. Offer Retry, Cancel Quit, and an explicitly destructive Quit Without Saving in an app-modal dialog that works without the main window. Reply once; release catalog access only on successful save or explicit discard. Cancel preserves changes and access and permits a later quit attempt.
4. Copy access: remove path-string fallback parameters and require a resolved, accessible security-scoped bookmark. Refresh stale bookmarks under the active grant when possible. Missing, invalid, or inaccessible bookmarks return a source/destination-specific reselection message; the existing folder picker recreates the bookmark. Existing cleanup releases acquired scopes and removes temporary include lists.

The JPEG writer does not acquire or release security scope. Copy scope ownership stays separate from the main catalog's scope. Quit cancellation does not run copy cleanup or disable file access. Model release changes do not touch persistence or export.
